## Kurzübersicht

- **Typ:** Klinik
- **Anzahl Punkte:** 45 (30 Pflicht + 15 Optional)
- **Zeitaufwand Packen:** Ca. 1-2 Stunden
- **Zeitpunkt:** Ab Woche 36 vorbereiten

## Was gehört in die Kliniktasche?

### 📄 Dokumente und Materialien

- [ ] Geburtsurkunde der vorherigen Kinder
- [ ] Mutterpass
- [ ] ID-Karte / Personalausweis
- [ ] Elektronische Patientenkarte
- [ ] Impfausweis
- [ ] Krankenversicherungskarte
- [ ] Kinderkrankengeld-Bescheinigung
- [ ] Arztbriefe (bei besonderen Vorerkrankungen)
- [ ] Geburtsplan (falls vorhanden)
- [ ] Stift und Block

### 👶 Für das Baby

- [ ] 2-3 Strampler (Größe 50/56)
- [ ] 2-3 Windeln (Größe 1)
- [ ] Babydecke oder Schlafsack
- [ ] Babyhaube
- [ ] Babysocken
- [ ] Windelcreme
- [ ] Babyflasche (falls nicht gestillt wird)
- [ ] Schnuller (falls gewünscht)
- [ ] Babyhandtuch
- [ ] Babywäsche (Kopf, Körper, Windel)
- [ ] Auto-Sitz (für die Fahrt nach Hause)
- [ ] Windeltragetasche

### 👩‍👧‍👦 Für die Mama

- [ ] Bequeme Schlafkleidung (z.B. Nachthemd)
- [ ] Haus- oder Pantoffeln
- [ ] Brustbüstenhalter (Still- oder Schlaf BH)
- [ ] Brustpflaster
- [ ] Stillkissen (falls gewünscht)
- [ ] Toilettenartikel (Zahnbürste, Shampoo, Duschgel)
- [ ] Handtuch
- [ ] Shampoo & Conditioner
- [ ] Haarbürste / Kamm
- [ ] Deo
- [ ] Lippenpflege
- [ ] Haarbügel / Haarspray (optional)
- [ ] Frische Socken (warm)
- [ ] Bequeme Unterhosen (wegwerfbar)
- [ ] Hygieneartikel (Binden, Damenbinden)

### 📱 Sonstiges

- [ ] Handy und Ladegerät
- [ ] Powerbank
- [ ] Kopfhörer
- [ ] Buch oder E-Reader
- [ ] Leichte Snacks (Nüsse, Riegel)
- [ ] Wasserflasche
- [ ] Kamera (optional)
- [ ] Beruhigende Musik/Playlist

## Tipps für das Packen

1. **Früh beginnen** — Packen Sie ab Woche 30
2. **Leicht zugänglich** — Legen Sie alles an einen Ort
3. **Klein und handlich** — Wählen Sie eine Tragetasche, die Sie selbst heben können
4. **Mann mit einbeziehen** — Er sollte wissen, was wo ist
5. **Flexibel bleiben** — Es gibt in der Klinik auch vieles vor Ort

## Was Sie NICHT brauchen

- [ ] Zu viel Kleidung (Sie werden ohnehin schweßen)
- [ ] Hochwertige Kosmetik (Sie haben keine Zeit dafür)
- [ ] Zu viele Snacks (Krankenhaus bietet Verpflegung)
- [ ] Teure Elektronik (Vorsicht vor Diebstahl)
