## Kurzübersicht

- **Typ:** Urlaub
- **Anzahl Punkte:** 50 (35 Pflicht + 15 Optional)
- **Zeitaufwand Packen:** Ca. 2-3 Stunden
- **Zeitpunkt:** Ab 1 Woche vor Abreise vorbereiten

## Was gehört in den Koffer?

### 📄 Dokumente

- [ ] Personalausweise / Reisepässe
- [ ] Geburtsurkunden der Kinder
- [ ] Krankenversicherungskarten
- [ ] Reiseversicherung
- [ ] Flugtickets / Buchungsbestätigungen
- [ ] Mietwagen-Dokumente
- [ ] Hotel-Bestätigung
- [ ] Notfallkontakte
- [ ] Reiseapotheke (verschrieben)

### 👶 Für das Baby/Kind

- [ ] Windeln (Tagesbedarf + 20%)
- [ ] Windelcreme
- [ ] Babywäsche (Strampler, Socken)
- [ ] Schlafsaal / Schlafsack
- [ ] Schnuller (mit Ersatz)
- [ ] Fläschchen und Nuckel
- [ ] Babynahrung / Brei
- [ ] Becherflasche
- [ ] Sonnencreme für Kinder (SPF 50)
- [ ] Insektenschutz
- [ ] Lieblingsspielzeug
- [ ] Decke / Kuscheltier
- [ ] Baby-Trage / Babyring

### 👕 Für alle

- [ ] Badeanzüge / Badeslips
- [ ] Sonnenbrillen
- [ ] Hüte / Kopfbedeckungen
- [ ] Sandalen / Schuhe
- [ - T-Shirts / Shorts
- [ ] Pullover / Jacke (für kühle Abende)
- [ ] Schlafanzüge
- [ ] Unterwäsche
- [ ] Socken
- [ ] Handtücher (Schnell-Trockner)

### 🏥 Reiseapotheke

- [ ] Fieberzäpfchen
- [ ] Wundsalbe
- [ ] Pflaster
- [ ] Desinfektion
- [ ] Elektrolyte (bei Durchfall)
- [ ] Anti-Allergiemittel
- [ ] Magentabletten
- [ ] Sonnenbrand-Creme
- [ ] Mückenabwehr

### 📱 Technik

- [ ] Handys und Ladegeräte
- [ ] Powerbank
- [ ] Kamera
- [ ] Adapter (bei Ausland)
- [ ] Spiele / Bücher
- [ ] Streaming-Dienste (falls verfügbar)

## Tipps für den Familienurlaub

1. **Früh buchen** — Familien haben höhere Nachfrage
2. **Flexible Flugzeiten** — Mit Kindern sind Verspätungen üblich
3. **Hotel-Check** — Babybett, Hochstuhl, Kinderbecken
4. **Reiseapotheke** — Nie vergessen!
5. **Pausen einplanen** — Nicht zu viel auf einmal
